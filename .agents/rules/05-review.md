# Review Rule

Review before rewriting.

Separate dimensions:
- structure/causality/pacing
- character motivation/agency/arc
- dialogue/subtext/voice
- prose/specificity/rhythm/repetition
- continuity
- genre expectations when relevant

Every actionable issue should include:
- severity: critical / major / minor / optional
- location
- problem
- why it matters
- evidence
- recommended intervention

Do not use an opaque aggregate quality score as the acceptance decision.
