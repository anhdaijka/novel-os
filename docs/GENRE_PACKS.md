# Genre Packs

Genre packs extend tracking and review; they do **not** replace the core architecture.

## Mystery / thriller

Track more explicitly:
- clues and clue visibility
- suspect hypotheses
- reader vs character knowledge
- red herrings
- reveal fairness
- threat/clock progression
- promises/payoffs

## Romance

Track:
- trust
- attraction
- vulnerability
- intimacy
- barriers
- misunderstanding state
- commitment
- relationship turning points

## Fantasy

Track:
- magic/system rules
- factions
- geography/travel constraints
- artifacts
- culture/religion
- economy/politics where plot-relevant

## Science fiction

Track:
- technology rules and limitations
- scientific assumptions
- causal consequences
- institutions/politics
- chronology

## Time travel / multi-timeline

Track explicitly:
- branch/timeline identity
- causality
- knowledge state by timeline
- object provenance
- paradox/exception rules

If this becomes too complex for Story Skills' markdown timeline, only then consider a specialized timeline tool.
