# Obsidian Setup

Open the **repository root itself** as the Obsidian vault. Do not copy story files into a separate vault.

## Recommended plugins

### Dataview

Use for human-facing dashboards over Story Skills/author YAML metadata. It does not own data.

Useful views:

- current characters/statuses
- open promises/questions
- POV distribution
- scenes by location/character
- editorial TODO

### Tasks

Optional editorial backlog: rewrite requests, research gaps, continuity repairs, proofing work.

### Canvas

Use for visual projections such as relationship maps, mystery boards, faction maps, and act architecture. Do not keep canonical facts only inside Canvas.

## Optional plugins

### Obsidian Git

Convenient if you want Git actions from the vault UI. Prefer meaningful semantic commits over frequent automatic snapshots.

### Advanced URI

Useful later for automation and deep linking. Antigravity can already edit repository files directly, so this is not required initially.

## Suggested Home dashboard

Create a note named `Home.md` after the story is initialized with links/views for:

- current chapter
- current arc
- open questions
- open promises
- recent author decisions
- continuity warnings
- editorial tasks
- research inbox

Keep dashboards derivative. Canon stays in Story Skills files and `author/`.
