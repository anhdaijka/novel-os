# Research to Canon Proposal

Use the Researcher and Narrative Director responsibilities, but do not write canon yet.

1. Read the relevant `research/verified/` evidence and its source/confidence notes.
2. Read the canonical world/story files the evidence might affect.
3. Separate real-world fact from fictional adaptation.
4. Propose the smallest necessary canonical changes.
5. Identify contradictions with existing canon or author boundaries.
6. For every proposed mutation show:
   - target file/entity
   - current canonical value
   - proposed value
   - evidence/source basis
   - narrative consequence
7. End with:

`AUTHOR GATE: PENDING`

Only after explicit author approval may the Director update canonical files and run Story Skills checks.
