# Start Authoring Session

Act as the Narrative Director.

1. Read `AGENTS.md`, applicable `.agents/rules/`, and `author/session-state.md`.
2. If `story.md` exists, run `npm run story:next` and `npm run story:doctor` before recommending work.
3. Build a minimum-sufficient context manifest.
4. Read only the canonical files required by the current focus.
5. Report:
   - last accepted checkpoint
   - current canonical state
   - open promises/questions relevant to the focus
   - blockers or contradictions
   - one recommended next authoring action

Do not draft prose and do not modify canon during session startup.
