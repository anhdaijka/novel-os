# Research

Research is evidence, **not canon**.

Suggested flow:

```text
inbox → verified → author decision → canonical story file
```

Create subfolders as needed:

- `inbox/` raw notes/leads
- `verified/` checked facts with sources and uncertainty
- `sources/` local bibliographic/source notes (not large copyrighted copies)

Use `templates/research-note.md` for source-grounded research.
